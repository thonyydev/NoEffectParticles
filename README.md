# No Effect Particles

A lightweight client-side Minecraft mod that removes status effect particles from players and mobs.

## Features

- Hide your own status effect particles
- Hide other players' status effect particles
- Hide mob status effect particles
- In-game configuration menu
- Changes apply instantly
- Fully client-side
- Works on vanilla servers
- Fabric and NeoForge support

## Configuration

The following options can be changed independently:

- Remove my particles
- Remove other players' particles
- Remove mob particles

Configuration is stored in:

`config/noeffectparticles.json`

### Fabric

The mod works without Fabric API.

Mod Menu is optional and provides access to the configuration screen.

### NeoForge

The configuration screen is available directly from the NeoForge Mods menu.

## Requirements

### Fabric

- Minecraft 26.2
- Fabric Loader 0.19.5 or newer

### NeoForge

- Minecraft 26.2
- NeoForge 26.2.0.88 or newer

## Installation

1. Install Fabric Loader or NeoForge.
2. Download the correct No Effect Particles jar for your mod loader.
3. Place it inside your `mods` folder.
4. Start Minecraft.

The mod does not need to be installed on the server.
